# مبادرة يمامه الهسي - للإغاثة الإنسانية في غزة

## فكرة المشروع
تهدف مبادرة يمامه الهسي إلى **تسهيل وصول المساعدات الإنسانية** إلى المستفيدين في قطاع غزة، خاصة في أوقات الأزمات، عبر منصة إلكترونية تعرض أنواع المساعدات، مواقع التوزيع، ومواعيدها، مع تمكين المستفيدين من تقديم طلبات المساعدة بسهولة.

## المشكلة
تشتت المساعدات وصعوبة معرفة المستفيدين بنقاط التوزيع.

## الحل
إنشاء **موقع ويب متكامل** يعرض:
1. أنواع المساعدات: غذاء، دواء، مياه، إيواء.
2. مواقع التوزيع حسب الأحياء/المناطق.
3. مواعيد التوزيع.
4. نموذج تسجيل طلب مساعدة مع عرض حالة الطلب.

## المستخدم المستهدف
- الأسر والمستفيدون المحتاجون داخل قطاع غزة.
- الفرق التطوعية والمبادرات الإنسانية التي تقدم المساعدات.

## أهم الميزات
- **Hero Section** جذاب يرحب بالمستخدم ويشرح المبادرة.
- **قسم الخدمات** مع أيقونات وصور لكل نوع مساعدة.
- **فلترة الخدمات** حسب الفئة باستخدام jQuery.
- **نموذج طلب المساعدة** مع DOM Manipulation للرد الفوري.
- **قسم فيديو** لرح المبادرة.
- Footerيحتوي على روابط التواصل الاجتماعي.
- تصميم*Responsive** متوافق مع الهواتف، التابلت، وسطح المكتب.
- تأثيرات الحركة (Animation) لظهور المحتوى بشكل جذاب.

التقنيات المستخدمة
- HTML5
- CSS3 + Bootstrap 5
- JavaScript + jQuery
- Font Awesome / Bootstrap Icons
- Media Assets: صور وفيديو داخل مجلد `assets/`

 # طريقة التشغيل
1. افتح **index.html** في أي متصفح حديث (Chrome، Firefox، Edge…).
2. جميع الملفات مرتبطة محليًا، ولا تحتاج لاتصال إنترنت إلا لتحميل Bootstrap وjQuery عبر CDN.
3. يمكنك تعديل الصور أو الفيديو داخل مجلد `assets/` حسب الحاجة.

## ملاحظات
- تم تصميم الموقع بأسلوب **Single-Page Application** لتسهيل التنقل بسلاسة بين الأقسام.
- جميع البيانات في قسم الخدمات يمكن تعديلها بسهولة عبر `js/main.js`.
- التفاعل والتحريك يعتمد على **jQuery وCSS Animations** لتجربة مستخدم سلسة.
